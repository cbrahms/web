Bisect Probe 2

A diagnostic scratch page used to isolate a theme-token rendering bug in the artifact viewer.

A. HARD-CODED COLOR — if you see this, markup + CSS render.

B. VAR COLOR — if this is invisible, the theme tokens are the bug.

C. REPORT — on the live page, an inline script fills this block at load time with the computed data-theme attribute, body background and color, --ground and --ink token values, the prefers-color-scheme: dark match, and the html element's classes. This static copy shows the pre-render placeholder.

Kept for reference: this probe confirmed that colors defined only inside [data-theme] blocks never apply in the un-stamped system-theme state.
